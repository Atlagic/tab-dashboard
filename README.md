# Tab Dashboard

This project is a customizable new-tab dashboard inspired by tools like Momentum, 
designed to make every browser tab both useful and visually pleasant.

When a new tab opens, the app displays a full-screen background image fetched dynamically from 
Unsplash, along with proper author attribution. The background changes automatically, keeping the 
experience fresh and inspiring.

The dashboard shows real-time information at a glance, including:
- The current time, updated continuously 
- Live cryptocurrency data (price, daily high, and daily low)
- Local weather information, based on the user’s geolocation

All data is loaded dynamically from public APIs, with graceful fallbacks in place to ensure the 
UI still works even if a request fails. The layout is intentionally minimal, focusing on clarity, 
readability, and fast loading times.

This project serves as a foundation for a modern browser extension or web app and can be easily 
extended with additional widgets, customization options, or user preferences.
